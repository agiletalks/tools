# DOs 客戶價值選擇器｜純 HTML 開發規格

## 1. 專案目的

製作一個可直接在本機瀏覽器開啟的單頁 HTML 工具，供工作坊參與者討論：

> AI 應該為客戶帶來哪些正向改變？

本工具用於 AI 客服導入的「邊界與方向」討論。

此階段只討論高層次的客戶價值，不討論：

* 使用情境
* 客戶族群
* 商品
* 功能
* 流程
* 畫面
* 技術方案
* AI 模型能力

最終產出為各小組選定的 3 條 DOs，以及每條 DO 對應的核心價值詞。

---

# 2. 使用情境

## 2.1 使用者

* 工作坊參與者
* 每組約 4–8 人
* 由小組共同操作一台筆電或平板
* 引導者透過投影說明操作方式

## 2.2 執行環境

工具必須符合以下條件：

* 單一 HTML 檔案
* 可直接雙擊開啟
* 不需要安裝程式
* 不需要網路
* 不需要後端
* 不使用 CDN
* CSS 與 JavaScript 全部內嵌
* 所有資料儲存在瀏覽器 LocalStorage
* 支援桌機與平板
* 主要最佳化解析度為 1366 × 768 以上

---

# 3. 核心任務

使用者需要完成三個步驟：

1. 從七個價值面向中選擇 3 個。
2. 從每個已選面向中選擇最多 2 個核心價值詞。
3. 確認並輸出該組的 DOs。

# 5. 整體頁面結構

頁面由以下五個區塊組成：

1. 頁首
2. 步驟導覽
3. 價值面向選擇區
4. 關鍵詞選擇區
5. DOs 成果區

建議採單頁式垂直流程，不進行換頁。

## 6.1 顯示內容

### 主標題

DOs

### 副標題

AI 應該為客戶帶來什麼正向改變？

### 操作說明

先選擇 3 個價值面向，再從每個面向中選出最重要的核心價值。

### 邊界提醒

# 9. 步驟一：價值面向選擇區

## 9.1 區塊標題

選擇三個最重要的價值面向

## 9.2 輔助說明

七個面向都可能重要，但本活動需要做出優先選擇。

## 9.3 顯示方式

七個價值面向以大型卡片呈現。

每張卡片顯示：

* 圖示
* 中文名稱
* 英文名稱
* 一句定義
* 選取狀態

## 9.4 選擇規則

* 最多選擇 3 個面向
* 未選滿 3 個時可自由選擇
* 選滿 3 個後，其他未選卡片進入停用狀態
* 點擊已選卡片可取消選擇
* 取消後，其他卡片重新恢復可選

## 9.5 計數器

區塊右上角顯示：

> 已選擇 X / 3

## 9.6 卡片狀態

### 未選取

* 白色或淺色背景
* 一般邊框
* 可點擊

### 滑鼠移入

* 卡片微幅浮起
* 邊框加深
* 游標顯示 pointer

### 已選取

* 明顯高亮
* 顯示勾選圖示
* 邊框加粗

### 停用

* 透明度降低
* 不可點擊
* 顯示提示：

> 最多選擇 3 個價值面向

---

# 10. 步驟二：核心價值詞選擇區

## 10.1 顯示條件

至少選擇 1 個價值面向後顯示。

若尚未選擇任何價值面向，顯示空白提示：

> 請先從上方選擇價值面向。

## 10.2 區塊標題

從每個面向中選擇核心價值

## 10.3 輔助說明

每個價值面向最多選擇 2 個詞，至少選擇 1 個詞。

## 10.4 顯示方式

每個已選價值面向顯示為一個獨立區塊。

區塊內容包含：

* 中文名稱
* 英文名稱
* 定義
* 關鍵詞按鈕
* 已選數量

範例：

理解 Understanding

讓客戶更容易看懂資訊、規則與流程。

已選擇 1 / 2

[清楚] [簡單] [容易理解] [有方向]

[條理清楚] [降低複雜] [找得到答案] [看懂下一步]

## 10.5 關鍵詞按鈕

使用膠囊型按鈕。

### 未選取

* 淺色背景
* 深色文字
* 可點擊

### 已選取

* 深色或主題色背景
* 白色文字
* 顯示勾選符號

### 選滿 2 個後

其他未選詞彙進入停用狀態。

## 10.6 選擇規則

* 每個面向最多選擇 2 個詞
* 每個面向至少選擇 1 個詞，才可完成步驟二
* 已選詞可以取消
* 取消大分類時，該分類已選詞彙一併清除
* 重新選回同一分類時，不恢復先前已取消的詞彙

---

# 11. 步驟三：DOs 成果區

## 11.1 顯示條件

選滿 3 個價值面向，且每個面向至少選擇 1 個核心價值詞後，啟用成果確認區。

未達條件時，成果區可顯示即時預覽，但「確認 DOs」按鈕需停用。

## 11.2 區塊標題

我們的 DOs

## 11.3 顯示內容

依照使用者選擇大分類的順序，顯示 3 條 DO。

每條 DO 顯示：

* 編號
* DO 原則句
* 所選核心價值詞
* 所屬價值面向

範例：

### 1. 讓客戶更容易理解複雜資訊。

核心價值：清楚、有方向

價值面向：理解 Understanding

### 2. 讓客戶更安心地相信資訊與服務。

核心價值：透明、可靠

價值面向：信任 Trust

### 3. 讓客戶更有能力自行完成事情。

核心價值：有掌控感、能自己完成

價值面向：自主 Empowerment

## 11.4 確認按鈕

按鈕文字：

> 確認 DOs

啟用條件：

* 已選擇 3 個價值面向
* 每個價值面向至少選擇 1 個詞

按下後：

* 將目前結果標示為已確認
* 顯示完成訊息
* 將步驟三狀態設為已完成
* 儲存確認時間
* 啟用成果輸出功能

完成訊息：

> DOs 已確認。你仍可返回調整，重新確認後將更新結果。

---

# 12. 成果輸出區

確認 DOs 後顯示。

## 12.1 完整模式

顯示：

* 小組名稱
* 日期與時間
* 三個價值面向
* 三條 DO 原則
* 各面向所選核心價值詞

## 12.2 簡報模式

只顯示：

* DOs
* 小組名稱
* 三條 DO 原則
* 每條 DO 的核心價值詞

簡報模式需要：

* 隱藏操作區
* 放大文字
* 適合投影
* 可使用 ESC 或按鈕返回

## 12.3 文字輸出格式

複製結果時，使用以下格式：

DOs 客戶價值選擇結果

小組名稱：第三組

1. 讓客戶更容易理解複雜資訊。
   核心價值：清楚、有方向

2. 讓客戶更安心地相信資訊與服務。
   核心價值：透明、可靠

3. 讓客戶更有能力自行完成事情。
   核心價值：有掌控感、能自己完成

---

# 13. 操作按鈕

成果區提供以下按鈕：

## 13.1 複製結果

功能：

* 將文字版成果複製到剪貼簿
* 成功後顯示提示：

> 已複製到剪貼簿

## 13.2 下載文字檔

檔名格式：

dos-小組名稱-YYYYMMDD-HHmm.txt

若小組名稱為空白：

dos-result-YYYYMMDD-HHmm.txt

## 13.3 列印／另存 PDF

呼叫瀏覽器列印功能：

```javascript
window.print()
```

列印時隱藏：

* 按鈕
* 操作說明
* 步驟導覽
* 未選項目
* 編輯介面

只保留：

* 標題
* 小組名稱
* DOs 結果
* 日期時間

## 13.4 簡報模式

進入全螢幕成果展示。

## 13.5 重新選擇

功能：

* 保留小組名稱
* 清除價值面向與關鍵詞選擇
* 清除確認狀態
* 顯示二次確認視窗

確認文字：

> 確定要清除目前的 DOs 選擇嗎？

按鈕：

* 取消
* 確認清除

## 13.6 清除全部

功能：

* 清除所有選擇
* 清除小組名稱
* 清除 LocalStorage
* 回到初始狀態

需二次確認。

---

# 14. 自動儲存

使用 LocalStorage 儲存以下資料：

* 小組名稱
* 已選價值面向
* 各價值面向選取的核心價值詞
* 是否已確認
* 最後確認時間

建議資料鍵值：

```javascript
customerValueDosState
```

建議資料結構：

```javascript
{
  groupName: "",
  selectedCategories: [
    "understanding",
    "trust",
    "empowerment"
  ],
  selectedKeywords: {
    understanding: ["清楚", "有方向"],
    trust: ["透明", "可靠"],
    empowerment: ["有掌控感", "能自己完成"]
  },
  confirmed: true,
  confirmedAt: "2026-07-15T10:30:00+08:00"
}
```

每次選擇、取消或輸入小組名稱時立即儲存。

頁面重新載入後，自動恢復先前狀態。

# 16. 視覺風格

## 16.1 整體風格

* 現代
* 清楚
* 專業
* 適合金融業工作坊
* 留白充足
* 大字體
* 高辨識度
* 避免過度裝飾

## 16.2 建議配色

可使用深藍與中性色作為主色。

建議 CSS 變數：

```css
:root {
  --bg: #f5f7fa;
  --surface: #ffffff;
  --primary: #173b6c;
  --primary-light: #e8f0fa;
  --text: #17202a;
  --muted: #667085;
  --border: #d9e0e8;
  --success: #217a55;
  --disabled: #c8ced6;
  --danger: #b42318;
}
```

各價值面向可以使用不同的輔助色，但不可影響文字可讀性。

## 16.3 字體

優先使用系統字體：

```css
font-family:
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  "PingFang TC",
  "Microsoft JhengHei",
  sans-serif;
```

## 16.4 字級

* 主標題：40–48px
* 副標題：22–26px
* 區塊標題：24–28px
* 卡片名稱：20–22px
* 卡片英文：13–15px
* 內文：16–18px
* 關鍵詞：16–18px
* 成果 DO 句：22–26px
* 操作按鈕：16–18px

# 17. 響應式設計

## 桌機

* 七張價值卡可採 4＋3 排列
* 關鍵詞區塊可採雙欄或三欄
* 成果區全寬顯示

## 平板

* 價值卡採 2 欄
* 關鍵詞按鈕自動換行
* 按鈕高度至少 44px

## 手機

手機不是主要使用裝置，但頁面不可破版。

* 價值卡單欄
* 操作按鈕滿版
* 簡報模式保持可閱讀

---

# 18. 可用性要求

* 所有可點擊區域高度至少 44px
* 不依賴滑鼠 Hover 才能理解內容
* 選取狀態不能只依靠顏色，需搭配勾選圖示
* 鍵盤可使用 Tab 移動
* Enter 或 Space 可選取卡片
* 清楚顯示目前選擇數量
* 達到上限時需給出即時提示
* 錯誤提示不可使用瀏覽器原生 alert，應使用頁面內 Toast 或 Modal

---

# 19. 邏輯規則

## 規則 1

價值面向最多選擇 3 個。

## 規則 2

每個價值面向最多選擇 2 個核心價值詞。

## 規則 3

每個已選價值面向至少需選擇 1 個詞。

## 規則 4

取消價值面向時，清除該面向所有已選詞。

## 規則 5

未完成所有選擇前，不可確認 DOs。

## 規則 6

確認後仍可修改，但修改後需將確認狀態改為未確認。

## 規則 7

確認後的結果才可下載或進入簡報模式。

## 規則 8

刷新頁面後需恢復目前選擇。

# 20. 空白與提示狀態

## 尚未選擇價值面向

顯示：

> 請先選擇你們認為最重要的價值面向。

## 已選擇面向，但尚未選詞

顯示：

> 請為每個價值面向選擇至少一個核心價值。

## 尚未選滿三個面向

顯示：

> 還需要選擇 X 個價值面向。

## 嘗試選擇第四個面向

Toast：

> 每組最多選擇 3 個價值面向。

## 嘗試選擇第三個關鍵詞

Toast：

> 每個價值面向最多選擇 2 個核心價值。

## 修改已確認結果

Toast：

> 內容已變更，請重新確認 DOs。

# 21. 列印版規格

列印格式建議為 A4 直式。

內容包含：

* DOs
* 小組名稱
* 產出時間
* 三條 DO 原則
* 每條 DO 的價值面向
* 核心價值詞

列印時不顯示：

* 步驟導覽
* 未選卡片
* 操作按鈕
* 提示訊息
* 頁面背景色

# 22. 驗收標準

## 功能驗收

1. HTML 可在無網路環境開啟。
2. 所有 CSS 與 JavaScript 均內嵌。
3. 可選擇最多 3 個價值面向。
4. 每個面向可選擇最多 2 個詞。
5. 可取消已選項目。
6. 可即時生成 DOs 預覽。
7. 未完成條件時不可確認。
8. 確認後可複製成果。
9. 確認後可下載 TXT。
10. 可使用瀏覽器列印成 PDF。
11. 可進入簡報模式。
12. 可使用 LocalStorage 恢復狀態。
13. 清除全部後可回到初始狀態。

## 內容驗收

1. 七個價值面向內容完整。
2. 每個面向包含 8 個核心價值詞。
3. 所有 DO 原則句皆為高層次客戶價值。
4. 畫面中不出現商品、功能、場景或技術選項。
5. DOs 輸出統一使用「讓客戶……」句型。

## 視覺驗收

1. 在 1366 × 768 畫面下無水平捲軸。
2. 字體清楚，適合工作坊投影。
3. 選取、未選、停用狀態明確。
4. 平板尺寸下可正常操作。
5. 列印版面無操作元件。

# 23. 開發限制

* 不使用 React、Vue 或其他前端框架
* 不使用 npm
* 不使用外部字型
* 不使用外部圖片
* 不使用第三方 JavaScript Library
* 不呼叫任何 API
* 不上傳任何使用者資料
* 不需要登入
* 不使用 Cookie
* 不使用伺服器

技術限定為：

* HTML5
* CSS3
* Vanilla JavaScript
* LocalStorage
* Clipboard API
* Blob 下載
* Fullscreen API
* Browser Print API

# 25. 最終使用流程

```text
輸入小組名稱
↓
選擇三個價值面向
↓
每個面向選擇一至兩個核心價值
↓
檢視 DOs 即時預覽
↓
確認 DOs
↓
複製、下載、列印或簡報展示
```
